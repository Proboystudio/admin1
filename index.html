Proboy Studio · Sign in with your Supabase Auth administrator account.

First-time setup
In the Supabase Auth Users page, create your email/password user. Then run this in SQL Editor to authorize that exact email:
insert into public.admin_users(email) values (lower('YOUR_EMAIL')) on conflict do nothing;
Replace YOUR_EMAIL with your admin email. Never put a database secret key in this page.
